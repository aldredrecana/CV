# CV

https://roadmap.sh/projects/single-page-cv

CV Project

A simple, semantic HTML page for my personal CV (Curriculum Vitae). Built as part of a roadmap.sh task focused on writing clean, meaningful HTML — no CSS styling yet, that comes in a future project.

About

This project shows my CV using proper HTML tags so the page structure makes sense to browsers, search engines, and screen readers — not just to a person looking at it.

What's Included
Semantic HTML — tags like <header>, <main>, <section>, <article>, <address>, and <footer> are used to describe each part of the page, instead of generic <div>s.
SEO Meta Tags — a description, keywords, and author tag in the <head> so search engines understand what the page is about.
Open Graph (OG) Tags — so the page shows a nice title, description, and image when shared on social media (Messenger, Discord, Facebook, etc.).
Favicon — a small icon linked in the <head> that shows up in the browser tab.

How to View

Just open index.html in any web browser. No build tools or installation needed.
